# 麦肯锡式结构化产出:咨询交付的格式

麦肯锡式咨询产出的精髓,是把"结论先行 + 金字塔结构 + MECE 分组"落到纸面上。这里沉淀一套可复用的产出格式,供结构化思维各 Agent 输出时套用。

## 一、总原则

1. **结论先行**:先给核心结论,再展开论据;先重要后次要、先全局后细节、先结论后原因
2. **每页/每段一个核心信息**:用"行动标题"(完整句子)直接概括本段结论
3. **金字塔三层**:核心结论 → 3-5 个关键论点 → 支撑事实/数据
4. **MECE 分组**:各组不重叠、无遗漏
5. **SCQA 开场**:情境(Situation)→ 冲突(Complication)→ 疑问(Question)→ 答案(Answer)

## 二、执行摘要格式(报告开头)

```
【执行摘要】
- 核心结论:[一句话,可指导决策的判断]
- 关键发现:[3-5 条,每条是一句完整结论]
- 核心建议:[明确的行动建议]
```

## 三、单条"发现"的标准格式

每条关键发现,用"结论句 + 支撑"结构:

```
[结论句](行动标题,一句话概括本条)
  ├── 支撑事实/数据 1
  ├── 支撑事实/数据 2
  └── 由此推出的影响/风险
```

## 四、行动标题 vs 标题

- **普通标题**:名词短语,只说明"这页讲什么"(如"市场分析")
- **行动标题**:完整句子,直接给出结论(如"市场将在 3 年内转向线上,应提前布局")

麦肯锡要求每页 PPT 用行动标题,让读者不看正文也懂结论。

## 五、SCQA 框架

- **S(Situation)**:当前公认的稳定状态/背景
- **C(Complication)**:打破稳定的冲突/变化/问题
- **Q(Question)**:由此引出的核心问题
- **A(Answer)**:答案 = 金字塔顶端的建议

例:"市场增长放缓(S),但我们的获客成本翻倍(C),如何在降本的同时维持增长(Q)?答案是聚焦 20% 高价值客户(A)。"

## 六、30 秒电梯法则

任何产出都应能压缩成 30 秒讲完:先结论,再讲 2-3 个最关键的支撑点。如果 30 秒讲不清楚,说明结构还没想透。

## 七、适用到三个 Agent

- **第一性原理 Agent** 产出:用 SCQA 开场 + 核心结论(根)+ 关键判断(服务对象)
- **MECE Agent** 产出:金字塔中层,结论先行列出拆解框架,再展开每个分类
- **80/20 Agent** 产出:执行摘要格式,先给聚焦结论,再给 3-5 个关键支撑信号
